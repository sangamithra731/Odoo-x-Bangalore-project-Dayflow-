# HRMS - Human Resource Management System

A complete Human Resource Management System built with MERN stack (MongoDB, Express.js, React, Node.js).

## Features

### Authentication & Authorization
- User registration with email verification
- JWT-based authentication
- Role-based access (Admin/HR and Employee)

### Employee Dashboard
- Quick access cards for profile, attendance, leave, and payroll
- Recent activity feed
- Real-time status updates

### Admin Dashboard
- Employee management
- Attendance overview
- Leave request management
- Payroll administration

### Profile Management
- View and edit personal information
- Profile picture upload
- Employment details
- Salary structure visibility

### Attendance Management
- Check-in/Check-out functionality
- Daily and weekly view
- Status tracking (Present, Absent, Half-day, Leave)
- Admin view for all employees

### Leave Management
- Apply for leave (Paid, Sick, Unpaid)
- Leave history
- Admin approval workflow
- Comments and notifications

### Payroll Management
- Employee payroll view (read-only)
- Admin payroll control
- Salary structure updates
- Month-wise payroll tracking

## Technology Stack

### Backend
- Node.js with Express.js
- MongoDB with Mongoose
- JWT for authentication
- Nodemailer for emails
- bcrypt for password hashing

### Frontend
- React.js
- Material-UI for components
- React Router for navigation
- Axios for API calls
- React Hook Form for forms
